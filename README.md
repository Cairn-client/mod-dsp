# Nebula Multiplayer Mod on Cairn

A fork of [NebulaModTeam/nebula](https://github.com/NebulaModTeam/nebula), the multiplayer mod for **Dyson Sphere Program**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod and the BepInEx build it runs on are published as a pack the launcher installs and updates.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Dyson Sphere Program in the Library, download the mod and press Play.

Each release of this repository is the pack the launcher downloads.
